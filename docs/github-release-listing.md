## Name

Copy Text Without Selecting

## Tagline

Copy text from web pages with a modifier-assisted click, without selecting it first.

## Short description

A free, local-first Chrome MV3 extension for fast text copying, local history,
keyboard shortcuts, and developer-friendly text transforms.

## Long description

Copy Text Without Selecting removes the drag-to-select step from everyday web
copying. Hold the configured modifier key and click a page target to copy its
useful text. Links can be copied as Markdown, visible text, or a resolved URL; tables as TSV; and form controls
as their current values.

The popup provides quick site controls and recent history. The options page adds
excluded-domain management, search and filters, local analytics, language
selection, safe handling for editable surfaces, and smart actions for JSON,
SQL, JWT, timestamps, case conversion, and Base64.

All history and analytics remain in the local Chrome profile. Preferences use
Chrome's settings sync when available. The extension has no project-operated
server, account, advertising, telemetry, cloud history, or companion app.
